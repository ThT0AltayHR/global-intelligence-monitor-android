QUICK START:
================================================================================

1. Extract this archive
2. Install .NET 8.0 SDK
3. Run: dotnet workload install maui
4. Run: dotnet restore
5. Create .env file with API keys
6. Run: dotnet maui run -f net8.0-android

For detailed instructions, see Docs/INSTALLATION.md

API INTEGRATIONS:
================================================================================

The application integrates with:
- USGS (Earthquake data)
- NewsAPI.org (News aggregation)
- The Guardian API (Breaking news)
- NIST NVD (Cyber vulnerabilities)
- Shodan.io (Cyber threat intelligence)
- FlightRadar24 (Real-time flights)
- MarineTraffic (Ship tracking)
- OpenWeatherMap (Weather data)
- And more...

API keys are required and should be stored in .env file

DEVELOPMENT:

UI Framework: .NET MAUI
Logging: Serilog
Testing: Xunit

Code follows:
- SOLID principles
- Async/await patterns
- Null safety with C# 12
- Repository pattern for data access
